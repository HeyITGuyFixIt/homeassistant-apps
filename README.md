# Home Assistant Apps

Home Assistant Apps/Addons.

## Installation

[![Add repository on my Home Assistant][repository-badge]][repository-url]

If you want to add the repository manually, please follow the procedure highlighted in the [Home Assistant website](https://home-assistant.io/hassio/installing_third_party_addons). Use the following URL to add this repository: `https://github.com/HeyITGuyFixIt/homeassistant-apps/`

## Apps

### ![Freenet](freenet/icon.png) Freenet

[Freenet](https://freenet.org/) is a peer-to-peer platform for apps that no company controls. Your computer becomes part of a global network, and the apps running on it can’t be taken down, don’t track you, and need no servers behind them.
